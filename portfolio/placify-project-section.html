🎓 Placify AI — Student Placement Prediction

An academic Machine Learning application that uses Decision Tree Classification to estimate student placement outcomes from CGPA, technical skills, internship experience and aptitude performance.

  • Built with Python, Pandas, Scikit-learn and Streamlit.
  • Includes model metrics, feature importance, Decision Tree visualization and probability output.
  • Includes secure account login, prediction history and personalized improvement guidance.
  • Documented dataset provenance, responsible ML use, security and deployment.
