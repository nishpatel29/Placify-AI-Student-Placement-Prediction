# Contributing to Placify AI

Thank you for your interest in the project.

## Before contributing

- Keep changes focused and documented.
- Do not submit real student/private data.
- Do not commit secrets or credentials.
- Preserve attribution and existing license notices.
- Test the application locally before opening a pull request.

## Pull requests

Please explain:

1. What changed.
2. Why the change was needed.
3. How it was tested.
4. Whether the model, dataset, database schema, or security behavior changed.
