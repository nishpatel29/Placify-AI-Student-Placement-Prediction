# Dataset Documentation

## Current dataset

`placement_data.csv` is a **synthetic/demo dataset** created for the Placify AI academic project.

It is not an official dataset from a university, government placement cell, recruiter, or other institutional placement authority.

## Why synthetic data is currently used

The project requires a compact four-input demonstration dataset aligned with the college case study:

- CGPA
- Technical Skills Score
- Internship Experience
- Aptitude Score
- Placement outcome

No authoritative public dataset was identified that both matches this exact schema and clearly permits redistribution as part of this repository. The project therefore does not claim that its synthetic observations are real students or real placement statistics.

## Responsible use

Do not use the dataset to estimate actual placement rates, compare colleges, rank students, or make hiring decisions.

## If replacing the dataset

Before adding a third-party dataset, record:

1. Dataset name.
2. Original publisher/creator.
3. Source URL.
4. License.
5. Date accessed.
6. Whether redistribution is permitted.
7. Any preprocessing or transformation performed.
8. Citation/attribution requirements.

Do not copy a dataset into this repository merely because it is downloadable. The dataset's license and redistribution rights must be checked first.
